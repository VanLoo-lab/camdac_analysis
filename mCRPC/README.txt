As a guide, the following files are used for figures in the CAMDAC paper (11 March 2026):

- Figure 1H-K: Percentage agreement in allele-specific CNAs between WGBS and WGS. See `scripts/main/fig2_mcrpc_cna.R`.
- Figure 3H: mCRPC pathway enrichment q-values before and after CAMDAC. See `scripts/pre/ora_by_purity_parallel.R`, `scripts/pre/ora_top_genes.R` and `scripts/main/fig_ora_v2.R`.
- Figure 3I: LUSC hypermethylation at the PAX6 promoter. See `scripts/archive/240924_fig_ora_dmr_top.R`.
- Figure 3J: Hypomethylated regions. See `scripts/main/fig_mcrpc_rhmr.R`.
- Figure 3K: Hypomethylated regions at CD1A and IFI6. See `scripts/main/fig_mcrpc_cd1ifi.R`.

- Figure S5F-H: Effect of coverage, purity and copy number on deconvolution HDI. See `scripts/pre/power_analysis_hdi_simluations.R`.
- Figure S6D: Differentially methylated positions between normal tissue samples. See `scripts/main/sfig_panel_dens.R`.
- Figure S10: Methylation SNV fit treescores. This analysis was performed in 2021. The scripts cannot be found, however, the relevant data should be present in the file `TRACERX_TREESCORE.tar.gz`.
